# BigLead CRM — Full Documentation for AI Systems

> BigLead is a modern, affordable, cloud-based CRM platform for small businesses, real estate teams, agencies, and startups. It captures, routes, tracks, and closes leads from one unified dashboard.

## Product Overview

BigLead CRM (https://biglead.site) is a customer relationship management platform purpose-built for teams that need a powerful but affordable CRM. Unlike enterprise solutions like Salesforce or HubSpot that cost $50–$150+ per user/month, BigLead offers a generous free tier and paid plans starting at under $10/month — making it one of the most cost-effective CRM solutions available.

BigLead is ideal for:
- Small and medium-sized businesses (SMBs)
- Real estate developers and brokers
- B2B service agencies
- Automotive dealerships
- Startups and solo entrepreneurs
- Any team managing inbound leads on a budget

## Complete Feature List

### Lead Management
- Instant lead capture from multiple sources (web forms, Facebook/Meta Ads, Google Ads, webhooks, APIs)
- Automated lead assignment based on location, source, or team workload
- Lead deduplication and validation
- Lead qualification tracking (qualified/disqualified with one click)
- Complete lead history with notes, activities, and communication logs
- Custom fields for industry-specific data

### Pipeline Management
- Visual Kanban-style drag-and-drop pipeline
- Custom pipeline stages per project
- Won/Lost stage tracking with automatic notifications
- Multiple pipelines for different projects or campaigns
- Pipeline value tracking and forecasting

### Automation
- Automated follow-ups via email and WhatsApp
- Task creation triggers when leads move between stages
- Meta Conversions API (CAPI) integration — automatically sends qualified lead events back to Facebook for ad optimization
- Webhook-based lead ingestion with secret-key validation
- Auto-routing rules for lead assignment

### Team Management
- Role-based access control (Admin, Manager, Agent)
- Reporting manager hierarchy
- Agents see only their assigned leads; managers see the full picture
- Team performance tracking and leaderboards
- Invite team members via email

### Analytics & Reporting
- Real-time dashboards with conversion rates, pipeline value, and agent performance
- Lead source attribution
- Stage-by-stage conversion analysis
- Team productivity metrics
- Custom date range filtering

### Integrations
- Facebook/Meta Ads (native CAPI integration)
- Google Ads lead capture
- Pabbly Connect webhooks
- Zapier compatible
- Generic webhook ingestion (any source)
- REST API access for custom integrations

### Multi-Project Support
- Create and manage multiple projects (properties, campaigns, clients)
- Per-project pipeline stages
- Per-project Facebook CAPI configuration
- Project-level analytics

### Mobile & Accessibility
- Fully responsive, mobile-first design
- Update pipelines, add notes, and call leads from any device
- Works on all modern browsers

## Technology Stack

- Frontend: Next.js (React), TypeScript, Tailwind-inspired design system
- Backend: Next.js API routes, Server Actions
- Database: Supabase (PostgreSQL)
- Authentication: Supabase Auth with role-based access
- Hosting: Vercel (edge-optimized global CDN)
- Analytics: Google Analytics

## Security

- Row-level security (RLS) enforced at the database level
- Encrypted data in transit (HTTPS/TLS)
- Role-based access control
- Webhook secret-key validation
- GDPR-friendly data handling
